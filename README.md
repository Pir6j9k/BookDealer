# BookDealer

Десктопное приложение электронного книжного магазина на **C# / WPF** с базой данных на **Microsoft SQL Server**. Учебный проект — проектирование и разработка базы данных и клиентского приложения для продажи электронных и бумажных книг.

## Возможности

В системе три роли:

| Роль | Что может |
|---|---|
| **Гость** | Просматривать каталог (поиск, фильтрация, сортировка), открывать ограниченную карточку книги и читать отзывы |
| **Покупатель** | Авторизация и регистрация; каталог; корзина; список чтения(избранные); отзывы и оценки (1–10); оформление и оплата заказа; скачивание купленных книг; профиль; жалобы на книги и отзывы |
| **Администратор** | Добавление, редактирование и удаление книг и пользователей; блокировка («заморозка») книг и пользователей; обработка заказов и жалоб; статистика платежей с диаграммой и экспортом в Excel и Word |

## Технологии

- **Язык и UI:** C#, WPF (Windows Presentation Foundation)
- **База данных:** Microsoft SQL Server, T-SQL
- **Доступ к данным:** Entity Framework (контекст `BookShopEntities`)
- **Архитектура:** двухзвенная клиент-серверная (клиент напрямую работает с БД), код-behind без MVVM

## Структура репозитория

```
BookDealer/
```

## База данных

БД называется **BookShop**. Скрипт `BookDealerScript.sql` создаёт базу, таблицы, представления, ограничения и заполняет их тестовыми данными.

### Таблицы

| Таблица | Назначение |
|---|---|
| `Roles` | Роли: Администратор, Покупатель, Гость |
| `Users` | Пользователи (логин, хэш пароля, email, отображаемое имя, роль, признак блокировки) |
| `Books` | Книги: название, автор, описание, обложка, текст, цена, признаки «бесплатная» и «заблокирована» |
| `Genres` | Жанры |
| `BookGenres` | Связь книг и жанров (многие ко многим) |
| `Reviews` | Отзывы и оценки книг (1–10) |
| `Complaints` | Жалобы на книгу **или** на отзыв (ровно одно из двух) |
| `CartItems` | Корзина — уникальная пара «пользователь + книга» |
| `ReadingLists` | Список чтения со статусами: «В планах», «Читаю», «Прочитано», «Заброшено» |
| `Purchases` | Покупки: цена, способ оплаты, статус, номер транзакции |

Статусы оплаты в `Purchases`: «Ожидает оплаты», «Оплачено», «Возврат», «Отменено».

## Установка и запуск

### Требования

- Windows
- Visual Studio с рабочей нагрузкой «Разработка классических приложений .NET»
- Microsoft SQL Server (скрипт рассчитан на уровень совместимости 160, т. е. SQL Server 2022 и новее)
- SQL Server Management Studio (рекомендуется)

### Шаги

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Pir6j9k/BookDealer.git
   ```
2. Откройте `BookDealerScript.sql` в SSMS. В начале скрипта в `CREATE DATABASE` заданы пути к файлам базы (`E:\Program Files\MSSQL17.MSSQLSERVER\MSSQL\DATA\...`) — **замените их на пути вашего сервера** или удалите блок `ON PRIMARY ... LOG ON ...`, чтобы SQL Server использовал значения по умолчанию.
3. Выполните скрипт — будет создана БД `BookShop` с тестовыми данными.
4. Откройте `BookDealer.sln` в Visual Studio.
5. В `App.config` проекта укажите строку подключения `BookShopEntities` к вашему экземпляру SQL Server.
6. Соберите и запустите проект (`F5`).
